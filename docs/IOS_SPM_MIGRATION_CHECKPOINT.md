# iOS Swift Package Manager migration checkpoint

Prepared 2026-11-06 on `chore/ios-spm-messaging` for review. This branch is separate from the Capacitor security hotfix already on `main`; it has not been merged or submitted to a store.

## Source changes

- Capacitor's `spm-migration-assistant` removed the CocoaPods Podfile, lockfile, and workspace and generated the CLI-managed `CapApp-SPM` package. All 14 installed Capacitor plugins supplied `Package.swift` and were included. The Xcode project now links the local package and uses `ios/debug.xcconfig` for `CAPACITOR_DEBUG`.
- The project-wide iOS deployment setting was `13.0` while the app target already required `15.6`. Capacitor's generator read the first setting and initially generated an incompatible iOS 13 package. Aligning the project setting to `15.6` lets `npx cap sync ios` generate an iOS 15 package; the app's effective minimum remains `15.6`.
- The app bundle ID `com.klavhub`, build `13`, signing team, push entitlement, URL scheme, and `GoogleService-Info.plist` resource remain in the project. The debug-only CocoaPods compiler flag was removed. `Package.resolved` pins one Firebase Apple SDK source at `11.15.0` and Capacitor Swift at `7.6.10`. CocoaPods previously pinned Firebase Messaging `11.7.0`; this is a Firebase minor update, with no Firebase major update.
